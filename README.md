# Portfolio Project

Welcome to the **Portfolio** repository. This project showcases a collection of visual assets, 3‑D models, and interactive web components that can be used as a personal portfolio or as a demo of WebGL/Three.js techniques.

## About

The repository contains:

- **3‑D models** (black holes, planets, etc.) in GLB/GLTF format.
- **Shader programs** for custom visual effects.
- A lightweight **frontend** built with Vite and plain JavaScript that loads the models and renders them using Three.js.
- Utility scripts and documentation for building and extending the experience.

## Features

- Interactive WebGL visualizations of astronomical objects (black‑hole, white‑hole, wormhole, starfield, etc.).
- Custom GLSL shaders for atmospheric and gravitational lensing effects.
- A collection of high‑resolution textures and fonts under `public/`.
- Modular source code in the `src/` directory, making it easy to add new objects or scenes.

## Installation

```bash
# Clone the repository
git clone https://github.com/your-username/Portfolio.git
cd Portfolio

# Install dependencies (Node.js 18+ required)
npm install
```

## Development

The project uses **Vite** for fast development builds.

```bash
# Start a development server with hot‑module replacement
npm run dev
```

Open `http://localhost:5173` in your browser to see the live demo.

## Running the Demo

After installing dependencies, you can build and serve the production version:

```bash
npm run build   # Create an optimized production build in ./dist
npm run preview # Serve the built files locally
```

## Assets

- **3‑D models** are located in `bin/assets/` (e.g., `black-hole`, `planets`).
- **Textures** are in `public/planets/` and `public/tech-icons/`.
- **Fonts** for the hitmarker UI are under `public/deadcrt-font/`.

Feel free to explore these directories for additional resources.
